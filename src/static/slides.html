一、20 页 PPT 答辩大纲

P1 · 封面

  • 主标题：CBT 练心场
  • 副标题：新手心理咨询师的 AI 实战陪练小程序
  • 参赛方向：心理服务产品设计
视觉：产品 Logo + 手机原型居中，米白+墨绿主色。

P2 · 一页讲清楚：这是什么？

  • 一句话：用 AI 扮演"智能来访者"，让新手咨询师随时练咨询、立刻有反馈、老师能看到。
  • 三大关键词：AI 陪练循证 CBT师生闭环
视觉：三枚图标（AI 来访者 / CBT 教材 / 师生） + 一句话 slogan。

P3 · 为什么做？三个真实痛点

  • ① 练不起：真实个案风险高；角色扮演假、缺乏防御与阻抗。
  • ② 反馈慢：教师一对多督导，学生平均要等 3–7 天才能听到反馈。
  • ③ 不反身：教学生分析来访者，却没给学生分析自己的工具。
视觉：三张痛点小插画 + 数据卡（93% 学生"不会开口"）。

P4 · 调研依据（一句话带过）

  • 3 所高校 / 2 家机构 · 6 名教师 · 47 名学生访谈。
  • Ericsson 刻意练习理论：即时反馈是技能习得核心条件。
  • CBT 教育文献：理论到实操的转化是培养瓶颈（Beck, Wright 等）。
视觉：小数据卡 + 三本文献封面缩略图。

P5 · 目标用户

  • 主要用户：心理/应用心理专业学生、新手咨询师（0–2 年）。
  • 教学用户：CBT 教师、实习机构督导。
  • 潜在用户：继续教育阶段咨询师、相关职业培训（医护/社工/教育）。
视觉：三个人物画像卡（头像 + 痛点标签）。

P6 · 产品整体结构

  • 三大 Tab：片段练习 / 完整咨询 / 我的周记
  • 两大系统：学习进度看板 / 师生作业系统
视觉：使用配套《产品架构与流程示意图》（public/architecture.html）截图。

P7 · 核心理念：三层进阶训练

  • 微技能（动作分解）→ 完整咨询（整场比赛）→ 自我觉察（反身训练）。
  • 对标运动员培养：分解练习 → 实战模拟 → 复盘反思。
视觉：三层金字塔图（下到上：技能→全个案→自我觉察）。

P8 · 模块一：片段练习（微技能训练场）

  • 5 大类共 7 个场景：基本技术 3 个 / 概念化 / 自动思维 / 中间信念 / 核心信念。
  • 每个练习：专属来访者档案 + 目标 + 技术要点（含"应该说/不要说"）+ 情境 + 建议轮次。
  • 举例：共情回应（流产后压抑悲伤的小周）、无条件积极关注（打了孩子极度羞耻的老陈）……
视觉：7 张练习卡片缩略图。

P9 · AI 智能来访者 ≠ 聊天机器人

  • 具备成长史、家庭关系、症状细节，不是通用陪聊。
  • 具备真实防御：回避、羞耻、挑衅、理智化、讨好、阻抗。
  • 具备跨会谈一致性：初期回避 → 中期动摇 → 后期领悟，会反复、会反弹。
  • 每轮回应都指向目标技术，逼学生做出真实临床判断。
视觉：左"通用机器人" 右"有档案的来访者"对比卡。

P10 · AI 督导师：六维评分 + 可多轮追问

  • 六维评分：倾听 / 共情 / 提问 / CBT 技术运用 / 咨访关系 / 结构化。
  • 练习结束即出：分数 + 亮点 + 改进建议 + 本次要点。
  • 支持多轮追问督导："刚才那句为什么不好？""如果他说……我怎么办？"
视觉：六维雷达图 + 追问对话框截图。

P11 · 模块二：完整咨询 · 4 个个案 × 6 次会谈

  • 林女士·产后抑郁（入门）：建立关系→行为激活→自动思维→挑战→中间信念→防复发
  • 赵先生·社交焦虑（进阶）：评估建模→注意力→暴露等级→暴露实验→信念→防复发
  • 郑女士·惊恐障碍（入门）：惊恐模型→接地→内感暴露→现场暴露→信念→巩固
  • 何女士·关系与低自尊（进阶）：关系模式→关系思维→检验→边界→自我关怀→防复发
视觉：4 张个案卡片 + 6 次会谈时间线节点。

P12 · 完整咨询的三个特色

  • ① 会谈目标核对卡：自动判定"✓ 已逐步达成 / ↗ 待推进"。
  • ② 下周个性化作业：本次会谈结束即生成家庭作业。
  • ③ AI 来访者情绪记录表：AI 以"来访者"身份自己填 DTR，供学生对照观察。
视觉：三张卡片（打钩 / 作业本 / 情绪表）。

P13 · 模块三：我的周记（咨询师自我觉察）

  • 把发给来访者的贝克 DTR 反向给咨询师自己，七步结构化记录：
  • 情境 → 自动思维+相信度 → 情绪+强度 → 12 种认知歪曲 → 7 个引导问题选 1 → 适应性反应+相信度 → 结果三问。
  • 按周本地保存、整周一次性提交老师；强度均为步进器选择，移动端友好。
视觉：七步流程图 + 周记页手机截图。

P14 · 学习进度看板

  • 累计练习次数、六维评分趋势、完成度、薄弱维度提示。
  • 让学生看见成长曲线，让教师看到班级薄弱点。
视觉：折线图 + 数据卡片。

P15 · 模块四：师生作业系统（关键创新）

  • 学生端：一键提交片段/概念化/会谈/周记；"我的作业"查看状态与评语。
  • 教师端：身份页底部教师口令隐藏登录，无需注册、不与学生数据混淆。
视觉：左右分屏 学生端界面 / 教师工作台界面。

P16 · 教师工作台：三级分级浏览

  • 类型（片段 / 概念化 / 完整咨询 / 周记）
  • → 主题 / 个案（基本技术 / 林女士抑郁 / …）
  • → 会谈阶段（评估与建立关系 / 行为激活 / …）
  • 待处理红点计数，一眼定位作业。
视觉：树状分组示意图 + 工作台截图。

P17 · 教师能看到什么 / 看不到什么（伦理设计）

  • ✅ 看得到：完整对话、学生每一次提问、向督导追问的问题、横纵向概念化表、整周周记。
  • ❌ 看不到：AI 督导给学生的评分与反馈（仅学生本人可见）。
  • 🟡 情绪周记：只"标记已查看"，不打分、不显示分数，保护坦诚表达。
视觉：✅/❌/🟡 三栏表。

P18 · 技术实现 · 三端跨平台

  • 前端：Taro 4 + React + TypeScript + Tailwind。
  • 后端：NestJS 模块化服务，统一 /api 与数据信封。
  • AI：双 Agent 提示词工程——来访者 Agent（人设/防御/阶段一致）+ 督导 Agent（结构化评分）。
  • 数据：PostgreSQL 云端作业 + 本地周记加密存储。
  • 三端一致：微信小程序 / 抖音小程序 / H5 一套代码。
视觉：技术栈图标列阵 + 三端手机并排。

P19 · 应用价值与推广

  • 科学性：严格循证 CBT 理论与标准化工具。
  • 创新性：双 Agent AI、三层进阶、伦理隐私分层。
  • 可实施性：扫码即用，已完成可演示原型与多端构建。
  • 推广：高校课程 / 培训机构 / 继续教育 / 可平移至其他流派与职业培训。
视觉：四个价值图标 + 推广路径箭头。

P20 · 结语 + 现场演示

  • 一句话收束："把昂贵的督导室装进口袋，让每一次练习都算数。"
  • 邀请评委现场扫码体验 / 观看操作演示。
  • 团队信息 / 联系方式 / 致谢。
视觉：产品 Logo + 二维码 + Thank You。
